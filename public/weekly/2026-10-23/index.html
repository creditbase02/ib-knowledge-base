每週信用市場摘要

2026-10-23

每週信用市場券商報告摘要及市場想法｜2026/10/23

本週重點

  • US IG： AI融資與情緒持續主導。Barclays預期提前籌資限制短期Spread tighten；BofA認為融資不確定性高，但除ORCL外hyperscaler發行仍低於資產負債表及集中度容量，信用波動回落後可能形成買點；JPM維持年底前建設性立場，等待Fed、財報與Oracle投資人日。GS則認為12月初前widen風險偏高，TD預期quality進一步decompress。
  • EU： JPM將年底EUR IG／HY Spread目標上調至110／375bps，法國主權、AI與能源風險使其維持防禦配置。TD對主權外溢保持審慎，並提出long OAT／short法國銀行；Barclays認為SenFin相對Main落後過度，建議賣出payer。GS略偏美元信用，預期歐元M&A發債由低基期增加。
  • HY： JPM指出美國HY Spread升至373bps、貸款三年Spread升至530bps，CCC與Telecom、Cable弱勢突出。BofA維持信用建設性觀點，但預估2027年HY與貸款違約率上升、回收率下降；GS偏好HY債相對貸款，美元HY偏B、歐元偏BB。JPM基金調查顯示現金減少、AI運算配置增加、Software仍underweight。

1. US IG

1. 利差觀點

  1. AI供給限制短期tighten： Barclays認為hyperscaler營收強，但資本支出持續增加；企業搶先取得資本使供給前置、融資成本與Concession提高，因此對短期Spread保持審慎。（Barclays）
  2. JPM等待催化，仍偏建設性： JULI由兩週前96bps升至101bps，但JPM認為負淨淨供給與企業獲利支持仍在，Fed會議、大型hyperscaler財報及Oracle投資人日可能改變AI情緒。（JPM）
  3. BofA認為情緒落後將帶來買點： BofA認為AI融資形式與價格不確定，但2027年GPU產能固定使資本支出預期應逐漸穩定；信用波動率預期追隨利率回落，較佳估值最終可支持需求，短期Spread仍可能略wider。（BofA）
  4. GS提高近端下行參考： GS維持年底US IG 82bps目標，但預期12月初前更波動，下行情境將適度超過3月93bps高點；TD六個月US IG目標維持95bps，並預期quality進一步decompress。（GS、TD）

2. 技術面

  1. 下週供給預估有差距： BofA估10/26–10/30發行$25–40Bn、10月全月$110Bn，TD估下週$45–50Bn；兩家本週實際發行分別約$23.7Bn與$24.2Bn，Fed會議與財報blackout影響發行窗口。（BofA、TD）
  2. JPM連續四週負淨淨供給： JPM過去四週發行$95Bn、到期及票息收入$122Bn，本週發行約$18Bn、再投資約$36Bn；下週再投資收入則降至$18Bn，仍預期11–12月淨淨供給偏低。（JPM）
  3. ETF承接與基金贖回分化： BofA高評等債基金及ETF合計週inflow降至$1.22Bn，其中ETF流入$4.97Bn、基金流出$3.76Bn；JPM週inflow約$1.5Bn，週四債券反彈後單日追蹤inflow達$1.9Bn。（BofA、JPM）
  4. 台灣避險後吸引力回落： JPM指出TWD避險成本升至2.86%，10年美元IG pickup降至155bps、30年降至127bps，隔夜淨買入週減37%至每晚$188Mn；TD另記錄8月海外淨買入美國企業債升至$38.628Bn，但仍預期全年買盤減少。（JPM、TD）
  5. 新券Concession增加： BofA本週平均Concession由約3bps升至7bps、break約tighten 1bp，供給減需求預估由本週+$4.0Bn升至下週+$14.5Bn，技術面轉弱。（BofA）

3. 相對價值

  1. AI需要選發行人與期限： Barclays觀察AI發行人Spread離散程度由24bps增至65bps，AMZN及GOOGL短端偏rich、長端近期cheapening；hyperscaler 2s5s與5s10s較一年前均steepen超過一倍。（Barclays）
  2. Front-end BB與BBB各有支持： Barclays偏好與AI關聯較低的front-end BB；GS則偏好美元IG BBB相對A及AA以增加Spread。BofA維持BBB中性，以降低組合beta。（Barclays、GS、BofA）
  3. Sector偏好存在差異： BofA核心策略偏Pipelines、Insurance、Utilities及Energy，減碼Consumer Products、Health Care與Food & Beverage；JPM Sector表偏銀行、Tobacco、Finance Companies、Metals/Mining、Aerospace/Defense及Healthcare，Energy與Technology則neutral。（BofA、JPM）
  4. 高價券相對低價券pickup增加： JPM同企業近似期限配對的高價券Spread pickup約9.1bps、為一年前2.6倍，hyperscaler平均約23.1bps；列示ORCL及多家Utilities配對可增加Spread並縮短duration。（JPM）
  5. 折價債轉CP與curve配置： BofA認為企業收購折價債、改以CP融資可降低債務與近端利息，並可能支持low-dollar-price債；curve維持5s10s偏steepen、10s30s偏flat。（BofA）

4. 其他值得關注的議題

  1. 融資容量尚未用盡： BofA估除ORCL外，主要hyperscaler的credit quality與集中度容量仍大於2027年底前預期發行；Barclays則指出信評顧慮將促使企業結合股票、可轉債、證券化、private credit與跨幣別債市。（BofA、Barclays）
  2. 本輪hyperscaler弱勢與7月不同： JPM指出自8月初以來沒有新美元hyperscaler發行，本輪主要集中ORCL、較像HY AI風險外溢；ORCL 2066年券Spread約353bps，企業信用分析師仍overweight且基礎情境不預期降至HY。（JPM）
  3. Energy相對Technology創24年最強： JPM觀察Energy由一年前較Technology寬32bps轉為窄38bps，能源價格模型可解釋大部分相對表現。（JPM）
  4. M&A發債與銀行風險管理： GS記錄美元M&A發債年初至今IG $177Bn、HY $55Bn；銀行財報穩健，但AI融資擴大亦提高其對直接、間接曝險及資本結構順位的關注。（GS）

2. EU

1. 利差觀點

  1. JPM上調年底目標： EUR IG／HY本週分別widen 12／25bps至118／408bps，JPM將年底目標由90／300bps上調至110／375bps，反映法國主權、AI與能源風險溢價。（JPM）
  2. 主權壓力外溢： JPM記錄OAT–Bund約172bps、週增34bps，BTP–Bund約124bps、週增17bps；TD觀察法國一度175bps並外溢Italy、Spain、Portugal與Greece，對歐洲維持審慎。（JPM、TD）
  3. GS保留更寬下行情境： GS年底EUR IG／HY目標維持88／315bps，近端下行參考128／446bps；持續大幅widen需經濟活動急速惡化，並非其基礎情境。（GS）

2. 技術面

  1. 銀行帶動EUR IG供給回升： JPM本週發行約€16Bn、銀行占€10Bn，10月累計約€26Bn；HY僅€0.8Bn。Fed、ECB及法國評等檢視等事件可能抑制下週供給。（JPM）
  2. 基金流出放緩但產品分化： EUR IG基金outflow €148Mn，歐洲HY inflow €86Mn由ETF支持，strategic funds則outflow €712Mn；JPM認為整體技術面相對總體波動仍尚可。（JPM）
  3. 年度供給與M&A壓力： JPM維持EUR IG／HY gross issuance €730／€140Bn目標；GS則為€850／€115Bn，並預期歐洲強勁策略型M&A將使相關發債由低基期增加。（JPM、GS）

3. 相對價值

  1. JPM維持防禦性相對交易： JPM偏好BB相對single-B、EUR HY相對貸款、IG Senior Non-Financials相對Bank Bail-In；五年期EUR IG相對curve兩端及EUR IG相對GBP IG交易亦維持。（JPM）
  2. TD long OAT、short法國銀行： TD認為法國銀行比主權約tight 50bps難持續，因政府最終承擔紓困；願採長期相對交易，同時保留短期可能受損風險。（TD）
  3. Barclays賣出SenFin payer： Barclays認為SenFin相對Main的落後大於cash及股票反映，且部位偏空、隱含波動偏貴，建議賣出January SenFin S46 strike 100bps payer，捕捉basis recompression與波動溢價。（Barclays）
  4. IG相對主權估值不利Insurance： JPM指出EUR IG約64%面額比同期限OAT更tight，28%比同期限BTP更tight，削弱其對Insurance投資人的相對吸引力；GS則偏EUR IG BBB相對A／AA、HY BB相對較低quality。（JPM、GS）

4. 其他值得關注的議題

  1. 天然氣高價與低庫存限制政策空間： JPM記錄TTF約€93/MWh、歐洲入冬儲氣約75%，高能源成本增加通膨、壓縮工業利潤及消費，並減少ECB處理金融壓力的空間；較暖冬季可能部分緩衝。（JPM）
  2. 美伊協議可能主要透過利率提振： JPM認為若達成協議，通膨與升息預期下降較可能反映於利率，總報酬較有利higher-quality信用；若主權壓力變成成長疑慮，各市場仍有decompression空間。（JPM）
  3. 歐洲整併與跨境買家： GS指出歐洲策略型M&A約$509Bn，Financials及Telecommunications為主要Sector；美國買家占28%，主要集中UK，企業整併比sponsor交易更活躍。（GS）

3. HY

1. 利差觀點

  1. CCC與Telecom、Cable弱勢突出： JPM美國HY Spread達373bps、CCC達1,146bps，Telecom及Cable 10月總報酬約-6.31%及-2.47%；BofA追蹤AI HY Spread亦升至400bps、相對非AI溢價191bps。（JPM、BofA）
  2. BofA看回復條件，GS仍警戒波動： BofA認為利率波動下降與良好Q3財報是Spread回復條件，但情緒仍使HY殖利率約8.2%；GS預期美元HY下行情境適度超過335bps，年底目標仍為295bps。（BofA、GS）
  3. 歐洲HY目標調整與低quality壓力： JPM將年底EUR HY目標升至375bps，本週CCC Spread週增121bps至1,489bps、總報酬-2.79%；GS維持315bps年底目標及446bps近端下行參考。（JPM、GS）

2. 技術面

  1. 美國HY發行低迷、基金outflow持續： JPM本週四筆新券約$3.4Bn、10月累計約$10.2Bn，基金週outflow約$1.1Bn、近九週$7.4Bn；BofA截至其資料日，本週約$1.7Bn新券，連續三週基金outflow約$2.4Bn。（JPM、BofA）
  2. 貸款供給超過CLO創設： JPM觀察10月淨發行約$23Bn、CLO新創約$10Bn；貸款相關產品連續17週inflow約$13.9Bn，但其中CLO ETF貢獻大。貸款價格高於par占比降至9.8%。（JPM）
  3. 再投資需求減少： BofA估下週HY到期及贖回約$2.7Bn、票息約$0.9Bn，低於本週內部需求$4.1Bn；全年發行預估$360Bn，10月及11月分別約$17.1Bn、$31.5Bn。（BofA）
  4. 基金現金與配置變化： JPM調查64檔HY基金3Q現金降至3.11%，貸款配置升至3.79%；HPC／AI配置增至3.65%，Software配置約4.26%、underweight 101bps。（JPM）

3. 相對價值

  1. GS偏HY債相對貸款： GS考量Software曝險、2028年貸款到期牆與有限carry pickup，兩地皆偏HY債；美元HY偏B、BB中性、減CCC，歐元則偏BB、B中性、減CCC。（GS）
  2. Barclays觀察信評遷移交易機會： Fallen angels的相對Spread通常降評前widen、降評後首月較快compression，rising stars則在升評前後較平穩tighten；Barclays認為降評附近可能提供切入機會。（Barclays）
  3. 貸款與私人信用定價比較： JPM記錄9月B3公開貸款forward-curve YTM約10.46%、private credit約9.34%，private credit新交易median coupon SOFR+500bps；公開與私人市場再融資競爭增加。（JPM）
  4. 基金持倉偏好與Sector差異： JPM基金調查顯示Energy、Gaming/Leisure及Telecom為主要overweight，Technology與Services為主要underweight；相對指數減少BB及CCC、增加single-B。（JPM）

4. 其他值得關注的議題

  1. BofA預估2027年違約率上升： HY未來12個月面額／發行人違約率預估2.5%／3.3%，貸款4.0%／3.9%；近端到期牆、distress上升與借款成本增加為主要原因。（BofA）
  2. 回收率下滑與商業模式風險： BofA預估2027年HY回收32點、first-lien貸款49點，低於本年迄今34及54點；AI取代及低實體資產Sector可能使hard default占比增加、回收較低。（BofA）
  3. Barclays預估升評浪潮正常化： 2027年rising stars估$30–50Bn、fallen angels $20–30Bn，降評集中少數大型企業，系統性疑慮有限；Campbell's與Celara為重要風險個案。（Barclays）
  4. Private credit放款減速與風險指標： JPM記錄9月direct lending約$10.4Bn、年減66%；KBRA發行人違約率2.5%，納入non-accrual後6.4%，2028年底前到期占比24%，高於公開貸款及HY。（JPM）
  5. 退出指數影響流動性： Barclays研究HY退出指數後月周轉率由約9%降至5%，IG則因約74%仍在其他指數中而較有韌性；JPM研究亦顯示HY平時周轉率高於貸款，持有人與交易方式是差異來源。（Barclays、JPM）
  6. CLO投資人更關注成長放緩： JPM CLO調查約70%預期未來一年接近零成長與溫和信用壓力，約88%預期4Q26 Tier 1 BSL AAA Spread高於當時水準；部分投資人轉向可提供duration的Treasury、TIPS及US IG。（JPM）
