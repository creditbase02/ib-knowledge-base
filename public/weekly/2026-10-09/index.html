每週信用市場摘要

2026-10-09

每週信用市場券商報告摘要及市場想法｜2026/10/09

<!-- weekly-extra-source-date: 2026-10-11 -->

本週重點

  • US IG： rate vol仍主導短期方向，但供給偏低、fund inflow及企業獲利支撐市場；BofA預期殖利率穩定後Spread再tighten，Barclays則認為高rate vol會使Spread暫留較高區間。TD預估年底Spread升至90–100bps、六個月target為95bps，並偏好hyperscaler相對提供seller financing的chipmaker。其他相對價值偏好包括US issuer、Pipelines、Insurance、Utilities與Energy，以及long BB／short BBB。
  • EU： 法國與義大利主權波動尚未演變成2011年式主權—銀行—企業危機，但銀行相對非金融的落後幅度可能仍不足；JPM新增做多EUR IG senior non-financials、相對Bank Bail-In，BofA則等待數據rollover與rate vol見頂後再增加信用風險。
  • HY： 9月sell-off主要由利率與流動性premium驅動，但低品質信用持續decompress；BofA在rate vol回落情境下看好Spread由fair-value range較wider端tighten，GS偏好USD HY相對EUR HY，JPM則警告distressed universe擴大且recovery rate仍低。

1. US IG

1. 利差觀點

  1. 殖利率穩定後才有較明確tighten空間： BofA認為rate vol偏高時IG Spread會先略wider，待殖利率穩定後tighten；投資人調查中78%受訪者視較wider Spread與較高yield為買點，並自2021年來首度預期未來三個月Spread tighter。（BofA）
  2. 利率仍主導市場情緒： Barclays認為較高利率有助供需technical且多數issuer基本面穩健，但rate vol維持高檔將使Spread暫留略高區間。（Barclays）
  3. GS目標至2027年中溫和tighten： GS預估USD IG Spread由目前81bps至2026Q4為82bps、2027Q1為80bps、2027Q2為78bps。（GS）
  4. TD預期年底回到較寬區間： TD認為供給低迷、fund inflow及rate vol初步穩定使Spread暫時約80bps，但AI、M&A及銀行財報後發債將帶來壓力；年底US IG Spread預估90–100bps，六個月target為95bps。（TD）

2. 技術面

  1. 近期供給偏低、銀行財報後將回升： BofA指出9月M&A相關IG供給達$72Bn、為至少2013年來新高，現有pipeline隱含約$175Bn供給；本週發行偏低，但下週銀行退出blackout後technical可能轉弱。（BofA）
  2. 3Q sell-off使total return轉弱： Barclays指出利率sell-off令3Q26 IG與HY total return降至2022年以來最弱季度，強勁供給與投資人轉審慎並存。（Barclays）
  3. 年度供給仍高： GS預估USD IG gross issuance為2026年$2.3Tn、2027年$2.4Tn；USD HY則由$340Bn升至$375Bn。（GS）
  4. TD見fund flow加速且下週供給回升： IG bond funds與ETF單週流入由$982Mn跳升至$10.637Bn；TD預估大型銀行退出blackout後，下週US IG供給為$35–40Bn，全年供給維持$2.2Tn。（TD）

3. 相對價值

  1. 偏好US issuer與防禦Sector： BofA因法國主權、Iran及歐洲升息風險偏好US issuer相對European Yankees，並Overweight Pipelines、Insurance、Utilities及Energy；BBB降至中性，Consumer Products與Health Care維持Underweight。（BofA）
  2. BB相對BBB出現價值： Barclays認為BB相對BBB及5年期UST便宜約10–15bps，建議long BB／short BBB。（Barclays）
  3. data-center融資偏好corporate bonds： Barclays在相近Spread下偏好槓桿較低、會攤還且流動性較佳的IG／HY corporate bonds，而非到期再融資與續租風險較高的ABS／CMBS。（Barclays）
  4. 偏好hyperscaler、降低chipmaker與Telecom風險： TD在風險調整後偏好做多hyperscaler及相關公司、相對做空承諾seller financing的chipmaker；Telecom則因Starlink技術優勢挑戰legacy business而失去青睞。（TD）

4. 其他值得關注的議題

  1. M&A規模可能下降但風險偏上行： Barclays預估未來12個月全球M&A量約下降10%至$2.8Tn，但此估計存在上行風險。（Barclays）
  2. 3Q26獲利與Rating仍具支撐： BofA指出US IG 3Q26 earnings consensus為年增21.5%，雖低於Q2仍強；9月Rating淨升級$36Bn。（BofA）
  3. BDC面臨2028年software到期牆： Barclays認為BDC估值將更受software maturity wall影響，且目前相對BB並不便宜；hybrid則應重視step-up，而非只看coupon floor。（Barclays）
  4. pension滿額提撥尚未轉為大量公司債買盤： 私營defined-benefit plan funded ratio升至114.48%、為逾25年高點，理論上有利股票轉向corporate bonds；但TD指出PRT規模與Treasury stripping仍小，不宜直接推論需求將大增。（TD）

2. EU

1. 利差觀點

  1. 主權風險尚未形成系統性信用危機： BofA指出銀行持有本國公債與企業依賴銀行貸款的程度均低於2011年，bank Spread未大幅高於corporate Spread，信用curve也少有倒掛；但法國仍須提出可信財政修正。（BofA）
  2. 等待數據rollover與rate vol見頂： 美國hard data、全球forward EPS與hyperscaler capex尚未明顯轉弱；BofA認為一旦數據轉弱、確認政策限制性，rate vol見頂將成為重新做多信用的訊號。（BofA）
  3. GS目標顯示Spread逐季tighten： GS預估EUR IG由目前97bps降至2026Q4 88bps、2027Q1 86bps及2027Q2 84bps；EUR HY則由344bps降至315bps、310bps及305bps。（GS）

2. 技術面

  1. primary與零售需求仍疲弱： JPM指出本週EUR IG issuance僅€6Bn、EUR HY僅€1.1Bn；EUR IG基金流出€113Mn並連續第七週流出，EUR HY則流入€91Mn。（JPM）
  2. 2027年發行量多數高於2026年： GS預估EUR IG gross issuance由€850Bn升至€900Bn、EUR HY由€115Bn升至€130Bn；EUR loans則由€75Bn降至€65Bn。（GS）
  3. 企業現金降低利息負擔： BofA指出Euro Area企業在關稅事件後累積創紀錄現金，France與Germany企業net interest payments下降、政府則上升，負Spread公司債可能更常見。（BofA）

3. 相對價值

  1. 做多senior non-financials、相對Bank Bail-In： 9月初以來Bank Bail-In相對senior non-financials只wider 3bps至9bps；若OAT與BTP未大幅回到初夏水準，JPM預期非金融將outperform銀行。（JPM）
  2. 做多EUR BB、相對single-B： B／BB Spread ratio六週內由2.22x降至1.84x，JPM認為single-B壓縮過度；過去18次逾2%的HY drawdown中，BB均在最差階段過後outperform。（JPM）
  3. rate-sensitive Sector接近oversold： Utilities、Financials與Real Estate相對Euro IG落後達4.5個標準差；若ECB持續反駁升息定價，BofA預期這些Sector可能轉為領先。（BofA）
  4. hyperscaler具防禦性但對市場方向敏感： EUR hyperscaler近兩週只wider 4bps，優於senior non-financials的9bps；JPM預期主權sell-off延續時可再outperform，若主權市場反轉且blackout後供給回歸則可能underperform。（JPM）

4. 其他值得關注的議題

  1. EUR IG相對HY交易獲利了結： JPM在約1.12%獲利後平倉做多EUR IG、相對EUR HY，因BB／BBB Spread ratio已回到較接近五年平均。（JPM）
  2. France問題具長期結構性： BofA指出France自1974年以來未有primary budget surplus，政府debt／GDP未隨疫情後全球趨勢下降，private non-financial debt／GDP亦高達214%。（BofA）
  3. Barclays偏好Main復甦並用Xover避險： Barclays認為Main仍可能落後CDX.IG，配置上偏好Main復甦trade並以Xover downside hedge控制尾部風險。（Barclays）

3. HY

1. 利差觀點

  1. 9月sell-off主要由利率與流動性premium驅動： BofA估算再融資與distressed到期損失合計只能解釋市場最wider時不到30%的約50bps變動，因此大部分反映rate vol與流動性premium；在rate vol回落及Q3 earnings韌性情境下，Spread可由275–325bps fair-value range較wider端tighten。（BofA）
  2. 低品質信用持續decompress： JPM指出HY Spread一週tighten 5bps至348bps，但CCC Spread升至1,091bps、為2023年3月以來最寬；Cable、Telecom與Housing亦明顯落後。（JPM）
  3. USD HY風險低於EUR HY： GS預估2027年US HY issuer-weighted default rate約4%，EUR HY約5%；EUR HY因到期牆較陡，且CCC再融資成本與Energy、Consumer壓力重疊而更脆弱。（GS）

2. 技術面

  1. loan市場flow強但價格與Spread轉弱： JPM指出leveraged loan Spread一週wider 13bps至500bps、交易高於par比率降至21.8%，但loan funds單週流入$1.9Bn、為2025年2月以來最大。（JPM）
  2. 近期到期牆推升再融資成本： BofA指出HY指數11%將於兩年內到期，可融資債券的再融資成本平均高於原coupon約110bps；但distressed到期債僅占0.9%。（BofA）
  3. 2027年USD HY發行量估升： GS預估USD HY gross issuance由2026年$340Bn升至2027年$375Bn，USD loans由$400Bn升至$500Bn；USD CLO則由$405Bn降至$360Bn。（GS）
  4. TD觀察HY與loan flow分化： HY bond funds與ETF單週流出由$1.174Bn降至$251Mn，leveraged loan funds與ETF流入則由$1.254Bn加速至$2.432Bn。（TD）

3. 相對價值

  1. 偏好USD HY相對EUR HY、EUR loans相對USD loans： GS認為HY風險在EUR較高，但loan風險在USD較高；預估2027年USD與EUR loan default rate分別約5%與4%。（GS）
  2. 兩地均偏好HY bonds而非loans： GS指出US loan浮動利率已傳導較高融資負擔，Software & Tech Services為主要distress來源；EUR loan雖較受偏好，Software、Materials、Healthcare與Media仍有壓力。（GS）
  3. AI相關HY相對大盤有韌性： BofA觀察AI-related HY在9月sell-off中outperform；loan technical整體仍強，但CCC與Cable弱勢顯示不能把flow支撐延伸為低品質信用改善。（BofA）

4. 其他值得關注的議題

  1. distressed universe擴張： JPM指出sub-$80 loans為$139.8Bn、Spread超過1,000bps的HY bonds為$73.0Bn，合計distressed universe達$212.8Bn、占leveraged credit 7.2%；Technology與Cable/Satellite合計占40%。（JPM）
  2. recovery rate遠低於歷史平均： LTM HY bond與first-lien loan recovery分別為31.7%與34.9%，低於post-GFC平均39.7%與56.1%；低headline default rate因而未完整反映損失嚴重度。（JPM）
  3. LME延後default但未解決結構問題： GS指出LME可延後payment default，卻未改善槓桿與現金流，repeat defaulter占比與違約後損失仍高。（GS）
