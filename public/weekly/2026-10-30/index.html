每週信用市場摘要

2026-10-30

每週信用市場券商報告摘要及市場想法｜2026/10/30

本週重點

  • US IG： Oracle限制新增債務、Meta發股改善部分AI情緒，但Microsoft $25Bn交易再度凸顯供給壓力。JPM預期報酬改善帶動inflow、年底淨供給下降，BofA則估11月供給$175Bn、Spread偏wider至年底；TD維持防禦，GS偏非AI IG compression及次順位風險。
  • EU： JPM記錄EUR IG／HY週tighten2／12bps，維持年底110／375bps，並因curve比率極度flatten，改建短端single-A steepener。BofA認為央行訊號可支持數週內tighten，偏出口企業、Euro BB與利率敏感Sector；GS仍偏美元相對歐元，能源及主權風險值得防禦。
  • HY： 美國HY及貸款反彈，但CCC與Telecom、Cable月內弱勢仍大。Barclays預估2027 HY供給$380–420Bn、貸款$450–490Bn，以到期牆推動再融資；BofA看PC新vintage復甦、舊組合違約壓力續增，JPM指出重複違約使貸款回收承壓，GS維持US HY偏B、EUR HY偏BB。

1. US IG

1. 利差觀點

  1. Oracle改善自身信用敘事，供給競爭仍在： Oracle限制至FY30新增gross debt約$10Bn、Meta提高股票融資，Barclays認為短暫緩解情緒但企業仍有搶先取得資本的誘因；JPM認為Fed未升息、MOVE回落與Oracle轉向債權人友善，使市場背景略改善。（Barclays、JPM）
  2. JPM等待inflow改善，BofA仍看年底壓力： JPM指出IG月總報酬+1.9%、2025年2月以來最佳，若利率不反轉，預期需求隨後改善、淨供給下降；BofA則認為11月供給及mark-to-market風險壓過估值吸引力，Spread偏wider至年底。（JPM、BofA）
  3. TD防禦，GS選擇非AI信用： TD依live LQD計算本週widen約3bps、Technology領跌，六個月US IG目標95bps；GS認為總體基礎情境仍足以支持正常營運信用，但左尾變厚、估值未便宜，不支持全面逢低買入，偏非AI IG compression。（TD、GS）

2. 技術面

  1. Microsoft推高當週供給，下週預估分歧： TD本週US IG供給$59.352Bn，BofA約$60Bn，均受Microsoft $25Bn帶動；TD在更多AI發行假設下估11/2–11/6為$50–60Bn，BofA因選舉及波動估$30–40Bn。（TD、BofA）
  2. 11月供給及再投資： BofA估11月供給$175Bn、上行風險較大，AI與M&A財報後窗口、10月backlog及較低利率為主因；JPM估下週到期與票息升至$29Bn，BofA供給減需求由本週+$43.1Bn降至下週+$9Bn。（BofA、JPM）
  3. ETF inflow與主動基金贖回並存： JPM本週IG相關基金inflow $4.416Bn，其中ETF $7.54Bn、共同基金outflow $3.124Bn；其認為稅損換倉可能促使主動共同基金轉主動ETF。BofA同類inflow約$4.35Bn，估企業IG實際需求約$1.4Bn。（JPM、BofA）
  4. 供給衝擊由dealer承接，新券Concession提高： JPM記錄dealer週四淨買入$6Bn、歷史第四大；BofA估週庫存增加$7Bn，平均Concession由7bps升至9bps，break約tighten2bps。（JPM、BofA）
  5. 2027 IG供給仍高但口徑不同： Barclays對指數合格IG＋144A估gross $2.1Tn、net約$1.2Tn；GS預估US IG gross $2.4Tn、net $1.15Tn。Barclays認為AI融資更多轉外幣與指數外渠道，長端供給年增幅較慢。（Barclays、GS）
  6. 海外承接分化： JPM指出十年美元IG對JPY避險後pickup升至14bps，但壽險近期最多僅溫和順風；TWD pickup降至142bps、隔夜淨買入降至每晚$55Mn。BofA亦認為日本壽險減外債計畫不致大幅改變近期需求。（JPM、BofA）

3. 相對價值

  1. Hyperscalers相對chipmakers與個券CDS： TD偏等風險long hyperscalers、short chipmakers，後者seller financing增加、前者有獨立融資能力；Barclays建議買AVGO五年CDS保護，以及AMZN五年保護或DV01-neutral 3s5s steepener。（TD、Barclays）
  2. ORCL basis與資本結構： Barclays建議賣ORCL 5.25% 2032年cash、同時賣五年或5.5年CDS保護，交易basis compression；GS偏Corporate Hybrids及美國大型Banks次債，以次順位溢價取代更低credit quality。（Barclays、GS）
  3. 低AI相關性Sector提供分散： GS建議增加IG Utilities、Financials及Healthcare/Pharma，HY則Energy與AI相關性較低；BofA核心策略偏Pipelines、Insurance、Utilities及Energy，Consumer Products與Health Care則underweight。（GS、BofA）
  4. Curve與quality各有判斷： BofA維持BBB neutral、5s10s偏steepen及10s30s偏flat；JPM本週十年券相對強、5s10s flatten至約24bps，整體10s30s steepen至約18bps；GS維持BBB相對A／AA偏好。（BofA、JPM、GS）
  5. GPU融資面對短端跨產品競爭： JPM估1–10年Spread產品約$21.1Tn、十年以上$4.5Tn，GPU融資較短、需求池大但須競爭ABS、CLO及MBS等多種產品；長端產品選擇較少，使hyperscaler供給集中度更突出。（JPM）

4. 其他值得關注的議題

  1. 2027基本面改善與利息保障下降並存： BofA認為AI及M&A之外借款少，典型IG企業槓桿可繼續下降，但低coupon再融資使利息保障受壓；估2027 IG EBITDA成長約5%、平均coupon再升17bps。（BofA）
  2. 伊朗避險成本提高： BofA指出Energy及非循環Sector已偏rich，仍偏美國發行人相對European Yankees；TD即使認為Energy Spread很tight，仍喜歡短期long Energy避險。GS建議保留總體避險，可利用局部rally重設保護。（BofA、TD、GS）
  3. 指數納入價值與portfolio trading： TD回歸估指數合格券較同條件不合格券tight約13bps，提高最低發行額可能使被剔除小券widen；10月US IG portfolio trading占比由17.7%降至16.4%，下週仍有219家IG企業公布財報。（TD）
  4. Hybrids與non-QM： Barclays估2027 hybrids gross $110Bn、net $60Bn，企業首次發行人成為結構性成長來源，hyperscalers則不太可能成為重要發行群；non-QM A1 OAS約83bps、option cost72bps，有效duration約3.2年並可能延長至約五年。（Barclays）

2. EU

1. 利差觀點

  1. 主權短暫改善支持信用反彈： JPM記錄EUR IG／HY本週tighten2／12bps至116／396bps，Moody's維持法國Aa3後OAT及BTP反彈，但法國GDP收縮後再轉弱；年底目標維持110／375bps。（JPM）
  2. BofA看央行支持，GS仍保留地區防禦： BofA認為自8月大幅重定價後估值更有趣，Fed不急升息與ECB口頭干預有利未來數週tighten；GS則認為高能源、主權與財政風險抵銷較少AI供給的優勢，仍偏美元信用。（BofA、GS）
  3. Quality分化仍重要： BofA指出全球CCC／HY Spread比率超過4倍、創高，若Fed最終須更多升息，離散不易正常化，偏Euro BB；GS EUR HY同樣偏BB、B neutral、CCC underweight，年底EUR IG／HY目標88／315bps。（BofA、GS）

2. 技術面

  1. Primary活躍但Premium提高： JPM本週EUR IG發行€14Bn、10月€40Bn，Schneider及P&G主導；HY約€5.7Bn，含Recordati約€4.5Bn。非金融senior新券20券平均Premium由月初11bps升至16bps，book coverage由3.1降至2.4倍。（JPM）
  2. ETF部分抵銷基金outflow： EUR IG基金outflow €248Mn、其中短duration流出€355Mn，ETF inflow €269Mn；HY outflow €118Mn、ETF inflow €217Mn，strategic funds outflow €529Mn。（JPM）
  3. Hyperscaler全年目標有未達風險： JPM今年歐元hyperscaler僅€23.5Bn、5月後無交易，下修後€50Bn全年目標仍可能未達，部分取決於Meta年底前是否發債。（JPM）
  4. QT持續移除買盤： JPM估ECB企業債組合2027每月縮€3.9Bn，上半年€4.7Bn、下半年€3Bn；若QT不變，持倉由目前約€250Bn降至2027年底€195Bn，幾乎撤回疫情期間購買。（JPM）

3. 相對價值

  1. JPM由belly轉向短端steepener： A級3–5／1–3年Spread比率由1.39降至1.16倍，JPM認為flatten幅度通常只見於急性壓力；平掉belly overweight、虧損3c，改建3–5／1–3年single-A steepener，偏好84bps的1–3年A級防禦配置。（JPM）
  2. 出口信用對沖歐洲消費情緒： BofA偏全球營收分散、尤其周邊國家的出口企業；出口股已顯著領先內需股，信用差距仍有限，Spain出口企業Spread仍相對wide。（BofA）
  3. 利率敏感Sector與French Banks分歧： BofA認為Banks、Utilities及Real Estate落後過度，ECB若12月升息後暫停將有利；GS對整體Banks較建設性、但French Banks維持underweight；JPM仍偏Senior Non-Financials相對Bank Bail-In。（BofA、GS、JPM）
  4. 防禦交易與跨產品配置： JPM保留BB相對B、HY相對貸款及EUR IG相對GBP IG；GS亦偏歐洲HY債相對貸款、IG BBB相對A／AA，並偏EUR IG CLO tranches相對USD同類以增加carry。（JPM、GS）

4. 其他值得關注的議題

  1. 天然氣與冷冬壓縮企業及家庭： JPM指出TTF突破€100/MWh、2022年以來首次，庫存低且近期預估至11月中偏冷；高能源價格可能壓縮Industrials利潤及家庭可支配所得。（JPM）
  2. 衰退估值與消費信心： BofA指出法國消費者對生活水準評價為1972年以來最低，英德信心亦降；其模型顯示IG、single-A及Senior Banks、Utilities、Autos較接近溫和衰退定價。（BofA）
  3. 美國選舉影響提高： Reverse Yankees占Euro IG約18%，BofA認為美國政治更重要，歷次期中選舉後Euro IG及HY多rally；JPM則關注選後伊朗再升級風險，惟非其基礎情境。（BofA、JPM）

3. HY

1. 利差觀點

  1. HY反彈但CCC月內仍弱： JPM美國HY週tighten10bps至363bps，Telecom及HPC週報酬約+2.30%及+1.86%；BofA指數tighten13bps至314bps、BB與B領先，CCC Spread持平約1,307bps，月內仍負報酬。（JPM、BofA）
  2. BB反彈收復相對便宜程度： Barclays截至週三BB／BBB 1–10年Spread比率由2.04降至1.88倍、低於一年區間中點；GS仍偏美元B而非將承接AI供給及duration風險的BB，AI項目融資neutral、CCC underweight。（Barclays、GS）
  3. 歐洲HY偏higher-quality： BofA認為Euro BB高利息保障、低槓桿提供保護；GS同樣偏BB，擔心高利率與到期牆將使槓桿企業承受再融資壓力，成長敏感Sector溢價仍低。（BofA、GS）

2. 技術面

  1. 美國HY低供給，ETF吸收需求： JPM本週五筆發行$4.4Bn、10月累計$14.6Bn，基金轉inflow約$1.3Bn、12週最高，主動基金仍outflow、ETF inflow；BofA截至其資料日週內發行$2.7Bn、基金inflow $1.2Bn。（JPM、BofA）
  2. 2027 HY到期牆推動再融資： Barclays估gross supply $380–420Bn，其中bond-for-bond $150–170Bn、bond-for-loan $80–100Bn；三年內到期占26%、創高，但CCC近端distress及高於coupon的yield限制可融資量。（Barclays）
  3. 貸款反彈但flow轉負： JPM貸款週報酬+0.32%、Spread519bps，above-par占比回升至14.4%；基金18週首度outflow $304Mn，10月net issuance $25.6Bn高於CLO新創$12.5Bn。（JPM）
  4. 2027貸款與內部需求： Barclays貸款專題估BSL供給$450–490Bn、不含repricing，再融資$220–250Bn，兩年內到期已達$154Bn；BofA則估下週HY到期贖回加票息約$4Bn、全年HY發行$360Bn及11月$31.523Bn。（Barclays、BofA）

3. 相對價值

  1. GS偏HY債相對貸款、次順位相對降低quality： GS考量Software曝險、貸款到期牆及有限carry pickup，兩地偏HY債相對貸款；跨市場偏Corporate Hybrids與美國Banks次債，浮息投資則偏CLO mezzanine相對貸款。（GS）
  2. PC債優於PE股權： BofA認為高利息支出、Software與Services股權underwater及退出受限使PE承壓；較佳新deal、Spread與條款支持PC新vintage，PC對BSL溢價可能隨借款人quality靠攏而compression。（BofA）
  3. 貸款基金選券與quality調整： JPM 3Q調查現金4.31%，相對指數季內加BB154bps、減B2 107bps及CCC37bps；Software13.27%、僅underweight14bps但yield低149bps，HPC0.74%、overweight46bps。（JPM）
  4. CLO AAA浮息carry： JPM spot yield回歸預示未來12個月AAA報酬約6.4%，相對Treasury模型4.1%；其認為浮息Spread可提供分散，Treasury則資本占用較低、流動性較高。（JPM）

4. 其他值得關注的議題

  1. PC復甦與舊組合壓力並存： BofA預估NTM PC發行$118Bn、增6%，新券Spread再widen20bps至540bps；NTM non-accrual新增率3.6%、2027發行人違約率7%，Software及再融資壓力仍拖累舊vintage。（BofA）
  2. BDC贖回與secondary發展： BofA認為非上市BDC贖回主要是股權問題、信用偏選擇性降評；PC secondary 1H26交易$20Bn，GP-led主導，2027估$40Bn，提供流動性與組合管理工具。（BofA）
  3. 重複違約壓低貸款回收： JPM指出2023年以來284次default actions中99次為repeaters；2026 first-lien repeaters回收27.25點、首次44.28點，HY則23.95／50.71點，近年差距擴大。（JPM）
  4. LME改變文件、管理人與CDS需求： Barclays模型發現新貸款文件保護比sponsor身分更能解釋相對定價；LME普及促進管理人規模集中、降低distressed美國HY CDS效用，並支持direct lending。（Barclays）
  5. CCC損失集中： JPM attribution樣本約59%企業正貢獻，但前20大拖累合計693bps，CSCHLD -164bps、ALTICE -67bps最突出；Sector中Cable、Telecom及Housing拖累最大，Healthcare、Technology及Energy提供抵銷。（JPM）
  6. AI融資與信貸成本重新定價： BofA追蹤美元跨市場AI融資約$572Bn，HY AI Spread自445bps回落至376bps、premium180bps；Barclays則估未來幾年chip financing每年$300–400Bn，多在指數外，HY data center明年潛在發行約$60Bn。（BofA、Barclays）
